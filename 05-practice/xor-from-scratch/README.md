# XOR 从零实现（不调用框架）

**目标**：用纯 Python 手写一个两层神经网络，让它学会 XOR —— 亲手把"前向 → 损失 → 反向梯度 → 参数更新"这条链条走一遍。

**为什么放这个仓库**：前面都是笔记（"在读"），这是第一个**能跑的代码产出**（"在做"）。

---

## 任务清单（按顺序打勾）

- [ ] ① 补全 `sigmoid()` —— 顺带记住它的导数 $s(1-s)$
- [ ] ② 补全 `forward()` —— 2 → 4 → 1 两层级联
- [ ] ③ 补全 `backward()` —— 链式法则：先算输出层误差，再回传到隐藏层
- [ ] ④ 补全 `train()` —— 循环：前向 → 算损失 → 反向 → 更新权重；每轮记录损失
- [ ] ⑤ 补全 `predict()` —— 输出四组输入的结果
- [ ] ⑥ 把每轮损失写进 `results/loss.csv`，把曲线截图放进 `results/`

## 怎么跑

```bash
cd 05-practice/xor-from-scratch
python3 xor.py          # 纯标准库，无第三方依赖（不需要 numpy / torch）
```

## 验收标准（自己核对，过了才算完成）

| 检查项 | 标准 |
|---|---|
| 训练收敛 | 四组输入 (0,0)(0,1)(1,0)(1,1) 的输出与 0,1,1,0 的误差 < 0.05 |
| 损失单调下降 | `results/loss.csv` 里的损失整体下降（允许小幅抖动） |
| 能讲清 | 能不看稿说清：为什么必须有隐藏层（单层 XOR 不可分）、$\delta$ 是怎么回传的 |
| 能改 | 把隐藏层从 4 改成 8、学习率从 0.5 改成 0.1，能预测会出现什么变化并验证 |
