# KV Cache（为什么解码要缓存）

日期：2026-09-21　来源：AI 日报 · 小概念

## 一句话

大模型生成文字时，把前面每个字算出来的 Key / Value 存下来重复使用，每步只算新来的那一个字 —— 省下的是计算量，花掉的是显存。

## 生活类比

写作业翻课本，如果每写一行就把整本书从头重读一遍，肯定疯；正常做法是把刚查过的几页**折个角**，下次直接翻回去。

## 要点

- 生成第 N 个字时，前 N−1 个字的 K、V 不变 → 缓存起来复用，不必重算
- 代价：显存占用随**上下文长度**线性增长，长文本推理的显存瓶颈大头在这里
- 相关的工程手段：PagedAttention（管理显存碎片）、前缀缓存（多请求共享公共前缀）、连续批处理
