# Web Mining（网络数据挖掘）

日期：2026-09-21　阶段：数据挖掘与信息检索

## 1. 这是什么

从**网页和用户网络行为**里挖出有用的信息与规律，是数据挖掘的一个分支。三大块：

| 子方向 | 挖什么 | 典型方法 |
|---|---|---|
| **内容挖掘** | 网页正文/图片里的信息 | 抓取、去噪、抽关键词与实体、情感分析 |
| **结构挖掘** | **超链接**结构反映的重要性与关系 | PageRank、链接分析、社区发现 |
| **使用挖掘** | 用户的点击流与行为日志 | 推荐系统、A/B 实验、搜索行为分析 |

**典型应用**：搜索引擎（爬取 → 索引 → 排序）、比价、新闻聚合、反作弊、推荐。

## 2. 生活类比

现成数据集像**超市切好的净菜**，打开就能下锅；网络上真实数据更像**菜市场的一堆菜** —— 得自己挑、洗、切，才谈得上做菜。
Web Mining 教的就是"挑、洗、切"（挖掘内容）+ "怎么把它做成菜"（预测建模）。

## 3. 为什么学这个（NUS 暑期研习的 Web Mining 课）

官网（sws.comp.nus.edu.sg/Web-Mining.html，2026-09-21 查）写的课程内容三块：

1. **manual mining of web content** —— 手动/系统地从网页里挖内容
2. **predictive modeling** —— 对挖到的数据做预测建模
3. **building recommender systems** —— 做推荐系统

课程动机（原文意思）：很多人做分析时默认数据能从 Kaggle 这类仓库直接下载，这**限制了能做的 AI 应用范围**；真实场景要自己从网页里取数据。

讲师：**Lek Hsiang Hui**（NUS SoC 信息系统与分析系；多次获 NUS 教学卓越奖，也在大数据分析领域创业过）。

> 与我的方向的关系：这一套 ≈ **RAG 的前半段**（抓取 → 清洗 → 建索引 → 检索），也是 AI4DB 里文本/向量索引与数据清洗的基本功。

## 4. 暑假前怎么准备（不贪多，三步）

| 步骤 | 做什么 | 产出 |
|---|---|---|
| ① 抓取入门（1–2 周） | Python `requests` + `BeautifulSoup`，抓一个静态站（如豆瓣读书 Top250） | 一份清洗好的 CSV |
| ② 理论打底 | 《Mining of Massive Datasets》(MMDS) 免费电子书：第 3 章相似度、第 5 章 PageRank、第 9 章推荐系统 | 每章一页笔记 |
| ③ 一个小项目 | MovieLens 数据集做协同过滤（item-item 或矩阵分解） | 跑出 RMSE 数字 + 一页说明 |
| ④ 补工具（可选） | `scikit-learn` 分类/回归/评估指标 | 能读懂课程 project 的 baseline |

资源：MMDS 官网 http://www.mmds.org/ · MovieLens 数据集 · scikit-learn 官方文档
