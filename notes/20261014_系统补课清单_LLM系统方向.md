# 系统补课清单（12 周 · 每周 3–4 小时）

**目标**：补上「计算机系统」这块硬基础 → 为 LLM 系统 / 分布式训练方向（CS2680 那类课）打底
**时间**：2026-10-14 起，约 45 小时总量
**原则**：**只读该读的** ✓ 不追求读完 ✗（OSTEP 50 章，我们只读 15 章左右）

## 第 1–5 周：操作系统核心（OSTEP，免费在线）

每周 = 读 2–3 章 + 做 1 个官方 homework（30–60 分钟 ✓）

| 周 | 读什么 | 为什么 |
|---|---|---|
| 1 | Ch.4 Processes · Ch.6 Direct Execution · **Ch.7 Scheduling** | ⭐ 调度是 LLM serving 里 batching / scheduling 的老祖宗 |
| 2 | Ch.13 Address Spaces · Ch.15 Address Translation · Ch.18 Paging | 内存管理 = KV-cache 管理的基础 |
| 3 | Ch.19 TLB · Ch.20 Swapping | 继续内存（难就跳过 ✗ 第一遍不求全 ✓）|
| 4 | Ch.26 Concurrency · **Ch.28 Locks** | ⭐ 并发是所有系统课/面试的硬通货 |
| 5 | Ch.30 Condition Variables · Ch.36 I/O Devices · Ch.40 File System | 收尾，把整条链串起来 |

**可跳过**：Ch.17 / 21–24 高级虚拟内存 · Ch.31–34 并发进阶 · Ch.41–44 日志与崩溃恢复 · Ch.45+ 分布式

**动手（很轻）**：OSTEP 官方 homework 都是 Python 模拟器 ✓
- `scheduler.py`（自己改调度策略，看吞吐/周转时间怎么变 ✓）
- `paging-policy.py`（页面置换策略 ✓）
- `threads-*.py`（并发 ✓）

## 第 6–8 周：把"看得见"的东西做一遍（选一个）

**方案 A（推荐 ✓ 有实感）**：MIT 6.1810 的 **两个 lab**（xv6 内核 ✓ 每个 4–6 小时）
- Lab: **System calls**（给内核加两个系统调用 ✓）
- Lab: **Page tables**（页表 ✓）
→ 做完对「进程 / 内存 / 系统调用」就有实感了 ✓ 面试也能讲 ✓

**方案 B（更轻 ✓ 纯读）**：CSAPP 第 6 章（存储层级）· 第 9 章（虚拟内存）· 第 12 章（并发编程）

## 第 9–10 周：ML 系统（免费在线书）

- Ch.1–2：ML 系统导论 + 深度学习基础（快速过 ✓）
- ⭐ Ch.6–8：模型训练 / 硬件加速 / **模型服务（serving）** ✓
- ⭐ Ch.9：推理优化（量化 · 剪枝 · 蒸馏 ✓）

## 第 11–12 周：直接看 CS2680 与论文（把前面接上）

- 讲义：CS2680 slides **1（导论）** + **8（agent 设计）** ✓
- 必读三篇（LLM serving 的奠基作 ✓）：
 1. **vLLM / PagedAttention** —— 把 KV-cache 当"分页内存"管 ✓ 正好接第 2–3 周 ✓
 2. **SGLang** —— 前缀复用 + 结构化生成 ✓
 3. （可选）**Orca 连续批处理** ✓
- 目标：能回答 CS2680 那 9 个问题里的**前 3 个** ✓
