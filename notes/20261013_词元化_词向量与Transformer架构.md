# 词元化、词向量与 Transformer 架构

日期：2026-10-13　课程：人工智能概论（LLM 基础）　阶段：02-transformer

## 1. 这次要解决什么

一次课把「文本 → 词元 → 向量 → Transformer」这条链串起来：为什么需要词元化、Token ID 为什么不能直接用、词向量怎么学出来、以及 Transformer 为什么取代了 RNN。

## 2. 词元化（Tokenization）

- 定义：把文本切成多个**连续表征**（词元）✓ 与"按流水逐字拆分"的方式不同 ✓
- **BPE（字节对编码）**：先按**字符**拆 → 再按**字符间出现频率**不断合并 ✓
 合并在**原有字符集**基础上进行、**不覆盖**原始字符 → 最终形成**词表** ✓

## 3. Token ID 与"为什么必须向量化"

- **Token ID 本质是编号索引** ✓ 只记录该词元在词表中的存储位置 ✓ **不含任何语义信息** ✗
 → 单用 Token ID 拿不到语义，对后续编码没有帮助 ✓
- **向量化的目的**：捕捉词元间的**语义关系** → 让**语义相近的词元在向量空间中相互靠近** ✓

## 4. Word2Vec：静态词向量

**两种结构（方向正好相反 ✓）**

| 模型 | 谁预测谁 | 类型 |
|---|---|---|
| **Skip-gram（跳跃模型）** | 用**中心词预测前后上下文** | 一对多 ✓ |
| **CBOW（连续词袋）** | 用**前后上下文预测中心词** | 多对一 ✓ |

（窗口 = 2 时，Skip-gram 是用中心词去预测**左右各 2 个**词 ✓）

**训练机制**
- Token ID → 从 **Embedding Matrix（词向量表，可训练权重矩阵）** 中取对应**行**作为词向量 ✓
- 目标：让预测结果不断靠近**真实上下文的概率分布** ✓
- 用**反向传播 + 梯度下降**更新词向量矩阵 → 达到稳定后停止 ✓
- 语义怎么来的：**上下文相似的词（如苹果 / 香蕉）在完成相同预测任务的过程中，向量会逐渐靠近** ✓
 注意：向量相近反映的是**语义与用法相似**，**不等于两个词含义完全相同** ✓

## 5. 语言模型演进：为什么最后是 Transformer

| 模型 | 做法 | 优点 | 局限 |
|---|---|---|---|
| **前馈 NNLM**（Bengio, 2003）| 取目标词前**固定数量**的词 → 向量化拼接 → 送入 MLP 预测下一词概率 | 用浅层神经网络**替代 N-gram 的词频统计**，泛化更强 ✓ | 只有**固定窗口** ✗ 处理不了长文本的全局依赖 |
| **RNN** | 按序列逐词处理，**前一词的输出参与后一词的隐状态**计算 | 能保留历史信息 ✓ 擅长序列数据与语言建模 ✓ | ① **长程依赖遗忘** ✗（后续 LSTM / GRU 用门控缓解）② **必须串行**：等上一词算完才能算下一词 → **训练慢** ✗ |
| **Transformer**（谷歌, 2017）| 用**注意力机制**直接建模序列中任意两位置的关系 | **并行处理** ✓ 兼顾长上下文与计算效率 ✓ | 成为 LLM 与多模态模型的**核心架构** ✓ |

- RNN 的两大痛点是 Transformer 的直接动机：**摆脱固定窗口 + 摒弃循环 → 并行加速** ✓

## 6. Transformer 核心组件

**Encoder-Decoder 整体**
- 由**编码器 + 解码器**组成，最初用于**机器翻译** ✓
- Encoder：接收自然语言文本 → 经**词嵌入 → 位置编码 → 注意力** → 输出向量表示 ✓
- Decoder：接收 Encoder 的向量 → 解码 → 生成目标翻译文本的**概率分布** ✓
- 架构图里的 **N = 注意力层数**（层层堆叠，上一层输出作为下一层输入 ✓）

**四大组件**

| 组件 | 作用 |
|---|---|
| 1. **词嵌入层** | 分散文本 → 连续向量（如今多**复用预训练好的词向量矩阵** ✓）|
| 2. **位置编码** | 补充**顺序信息** ✓ —— 弥补**注意力机制本身不具备位置感知**的缺陷 ✓ |
| 3. **自注意力（Self-attention）** | **核心计算模块** ✓ 外层包裹**多头注意力（Multi-head）** ✓ |
| 4. **Masked Self-attention / Cross-attention** | 分别负责解码器的**自回归约束**与**跨编码器信息交互** ✓ |

**工程现状**：词元化、词向量读取等基础算法**已被封装成固定库**，不需从零实现；训练时直接按 Token ID 读取他人预训练好的词向量 ✓
