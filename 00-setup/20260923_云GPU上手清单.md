## 验收标准（就一条）

```bash

```

## 省钱与防坑（新手血泪）

| 坑 | 做法 |
|---|---|
| 忘记关机 = 一夜几十块 | 用完**立刻关机**；开机时选**同一张卡**，否则数据要重新传 |
| 数据丢失 | 数据放**数据盘**（系统盘重置会清空） |
| 装包很慢 | 先 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple` |
| 长任务掉线 | 用 `tmux`：`tmux new -s work` → 跑任务 → `Ctrl+B D` 挂起；`tmux a -t work` 回来 |
| 显存被占满 | 跑前 `nvidia-smi` 看一眼；OOM 就减 batch size |

## 常用命令速查

```bash
nvidia-smi                                   # 看显卡/显存占用
python -c "import torch; print(torch.__version__, torch.version.cuda)"
tmux new -s work / tmux a -t work            # 会话保护
pip install -U <pkg> -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 常见报错与解法

| 报错 | 原因 / 解法 |
|---|---|
| `False`（cuda 不可用） | 镜像选错了（装的是 CPU 版 torch）→ 换官方 PyTorch 模板镜像 |
| `CUDA error: no kernel image is available` | torch 与显卡算力不匹配 → 换更新的镜像，别自己编译 |
| `CUDA out of memory` | 减 batch size / 用 `torch.cuda.empty_cache()` / 换大显存卡 |
| 网页连不上 | 实例已关机或到期 → 重新开机（注意选同一张卡） |
