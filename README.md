## 笔记的固定格式

1. **这次要解决什么**（一句话）
2. **怎么跑的**（完整命令 + 数据规模 + 硬件）
3. **结果**（数字 / 图 / 报错原文）
4. **踩的坑与解法**（最重要，别省略）
5. **还没搞懂的**（诚实留白，比硬装懂好）

## 代码的规矩

- 命名：`日期_主题.py`，如 `20261001_mnist_train.py`
- 文件开头写注释：跑什么任务 + 依赖 + 运行命令
- **能跑通再提交**，把运行输出粘进对应笔记
